# Pizza_sales_analysis_using_SQL_queries
🍕 Pizza Sales Analysis Using SQL
📄 Project Overview

This project analyzes a pizza shop’s sales data using SQL to uncover key business insights — such as revenue performance, top-selling pizzas, order trends, and customer preferences.

🎯 Objective

To identify revenue drivers, sales patterns, and optimization opportunities for improved profitability and efficiency.

🧩 Dataset

The dataset includes four CSV files:

orders.csv — Order-level details with date and time.

order_details.csv — Quantity and pizza IDs per order.

pizzas.csv — Pizza prices and sizes.

pizza_types.csv — Categories and ingredients.

🔍 SQL Analysis Performed

Total revenue generated

Top 5 best-selling pizzas by revenue

Slow-moving pizzas with lowest sales

Average order value (AOV)

Orders by day of the week and month

Distribution of orders across morning, afternoon, evening, and night

Most popular pizza sizes and their revenue share

Category-wise revenue contribution (Classic, Veggie, Chicken, Supreme)

Comparison of weekend vs. weekday sales

Pareto (80/20) analysis for top revenue pizzas

📊 Key Insights

Evening hours show the highest number of orders (dinner peak).

Classic pizzas dominate order quantity, while Supreme and Chicken lead in revenue.

A few premium pizzas generate most of the revenue despite lower sales volumes.

Balancing affordable high-volume pizzas with premium high-margin items can boost total revenue.
